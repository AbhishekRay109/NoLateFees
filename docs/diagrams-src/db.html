Design choices

Soft deletes + created/updated times on every user table, so cloud sync can be added later without reshaping data.
Dates as text ('2026-11-30') so a due date never shifts a day across time zones.
Money in minor units (paise), never floats.
UUID v7 ids made on the phone: sortable, collision-free.
